Welcome to OAuth2 Server

This is a standards-compliant OAuth2 and OpenID Connect server implementation in Go.

Features
  • OAuth2 Authorization Code Flow with PKCE
  • OpenID Connect UserInfo endpoint
  • JWT Access and Refresh Tokens
  • Device Authorization Flow
  • Dynamic Client Registration
  • External Identity Provider support (Google, GitHub)
Quick Start
# Start the server
docker-compose up -d

# Access the server
open http://localhost:8080

# OpenID Discovery
curl http://localhost:8080/.well-known/openid-configuration

# JWKS
curl http://localhost:8080/.well-known/jwks.json
Test Authorization
Authorize with Default Client
API Endpoints
Endpoint Method Description
/.well-known/openid-configuration GET OIDC Discovery
/.well-known/jwks.json GET JSON Web Key Set
/oauth2/authorize GET Authorization endpoint
/oauth2/token POST Token endpoint
/oidc/userinfo GET UserInfo endpoint
/oauth2/revoke POST Token revocation
/oauth2/introspect POST Token introspection
/oidc/register POST Dynamic client registration
